What is actually happening?

Each item in the original array is passed into the function. The function transforms that item and returns a new value.

Take an item → Transform it → Return the result → Repeat

The callback

What is "number"?

It's simply the variable name we chose for the current item. When the first item is processed, number is 1. Then it becomes 2, then 3, and so on.

Important

The original array stays unchanged.

map() creates a new array containing the transformed values.

The takeaway

map() = take every item → transform it → collect the results.

Once you can see that movement, the syntax becomes much less scary.
